# Simon Dupong — Landing Page

Landing page premium et immersive conçue pour présenter l’identité, le parcours, les activités et la vision de **Simon Dupong**, entrepreneur.

Le site adopte une direction artistique moderne et cinématique, avec une expérience visuelle pensée pour mettre en valeur son image et son parcours.

## ✨ Présentation

L’objectif de ce projet est de créer une présence digitale élégante et professionnelle permettant de :

* présenter Simon Dupong et son identité ;
* mettre en avant son parcours ;
* présenter ses différentes activités ;
* partager sa vision et ses engagements ;
* faciliter la prise de contact ;
* offrir une expérience moderne et immersive aux visiteurs.

## 🎨 Expérience utilisateur

La landing page repose sur une interface sombre et minimaliste, accompagnée d'une identité visuelle jaune distinctive.

Le Hero principal utilise des animations au scroll pour faire progressivement apparaître le nom et le portrait de Simon Dupong.

L'expérience est également adaptée aux appareils mobiles afin de conserver une navigation fluide et une présentation cohérente sur différentes tailles d'écran.

## 🌍 Multilingue

Le site est disponible en :

* 🇫🇷 Français
* 🇬🇧 English

L'internationalisation permet de changer de langue directement depuis la navigation.

## 🛠️ Technologies

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* React Three Fiber
* Three.js
* i18next
* React Icons / Lucide

## 📱 Responsive Design

L'interface est conçue pour fonctionner sur :

* ordinateurs ;
* tablettes ;
* smartphones.

Une attention particulière est portée à l'expérience mobile, notamment au positionnement du portrait, à la lisibilité du contenu et aux animations.

## 🚀 Objectif du projet

Ce projet illustre la conception d'une **landing page personnalisée orientée image de marque**, combinant développement frontend, direction artistique et animations interactives.
